**Arknights: Endfield** is now on **Steam**, which makes playing it on Linux far simpler — no separate launcher and no manual Wine prefix.

The setup is now:

1. Install **Proton Plus** (the Flatpak is the easiest way).
2. Open Proton Plus, select **Steam**, and download the latest **Dawn Wine Proton**.
3. Close and reopen Steam so it registers the new build.
4. Install **Arknights: Endfield** from Steam, then open its **Properties → Compatibility** and force the **Dawn Wine Proton** build.
5. Launch.

Dawn Wine Proton is the build most likely to work. If it fails, other Proton versions probably will not help either — the cause is more likely game files, permissions or drivers, so ask in the Discord instead of cycling through runners.
