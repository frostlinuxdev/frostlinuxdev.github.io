## Fix: install freeze (Wayland or X11)

### Wayland: enable Wine Wayland

Try this first unless you are on X11 or Linux Mint. In Faugus, add this launch argument. In Heroic, switch on Wine Wayland in the game's settings.

```bash
PROTON_ENABLE_WAYLAND=1
```

![Heroic Wine Wayland switch](/images/czn/image2.webp)
![Faugus Launcher Wayland setting for Stove](/images/czn2/image7.webp)

### X11 and Linux Mint: virtual desktop

For X11 sessions (i3, XFCE, Qtile, dwm, Linux Mint and so on), use this instead of Wayland:

1. Open **Settings > WINECFG** (Faugus: **Tools > WINECFG**).
2. Click **Install** to open the configuration window.
3. Go to the **Graphics** tab.
4. Check **Emulate virtual desktop** and adjust the size if you like.
5. Click **Apply**, then **OK**.

![Winecfg for X11](/images/czn2/image8.webp)
![Wine configuration install window](/images/czn/image4.webp)
![Wine Graphics tab with Emulate virtual desktop enabled](/images/czn/image5.webp)

To revert, uncheck **Emulate virtual desktop** or disable Wine Wayland again.

### Lutris

Lutris is available on [Flathub](https://flathub.org/en/apps/net.lutris.Lutris).

1. Open the Lutris settings for the game and add `PROTON_ENABLE_WAYLAND=1`.
2. For a virtual desktop, select the game, press the arrow to reveal the menu, choose **Wine configuration** and enable **Emulate virtual desktop**.

![Lutris environment variable for Wine Wayland](/images/czn/lutrisimage2.webp)
![Lutris Wine configuration with virtual desktop enabled](/images/czn/lutrisimage1.webp)

## Stove not launching (crashpad_handler.exe)

If **Stove** no longer launches after following the normal guide, it is probably caused by **`crashpad_handler.exe`**.

1. **Open your Wine prefix.** In Heroic go to **Settings > Game Options > Wine Prefix** and click **Browse Wine Prefix**.

   ![Heroic settings with Browse Wine Prefix](/images/czn/image10.webp)

2. Navigate to this path inside the prefix:

   ```text
   drive_c/ProgramData/Smilegate/LauncherService/App/
   ```

   ![Wine prefix folder containing crashpad_handler.exe](/images/czn/image7.webp)

3. Find `crashpad_handler.exe` and either delete it or move it to a different folder.
4. Launch Stove again. It should start normally.

## Frequently asked questions

**Can you play Chaos Zero Nightmare on Linux?**
Yes. Install Stove and Microsoft Edge WebView2 in a Wine prefix with Faugus Launcher or Heroic Games Launcher.

**Which launcher should I use?**
Faugus Launcher, because Heroic has had issues after the Season 2 update. Heroic still works for many people.

**Why does Stove not launch?**
Usually `crashpad_handler.exe`. Deleting it or moving it out of `drive_c/ProgramData/Smilegate/LauncherService/App/` fixes it.

**How do I fix the install freeze?**
Enable Wine Wayland, or on X11 or Linux Mint enable Emulate virtual desktop in WINECFG.

**Do I need WebView2?**
Yes. Stove requires the Microsoft Edge WebView2 runtime.
