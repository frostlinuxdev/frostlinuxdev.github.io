Wuthering Waves runs on Linux through **Steam** with the **DW-Proton** compatibility tool. DW-Proton is installed with **ProtonPlus**, and you then tell Steam (or ProtonPlus) to use it for the game. This guide covers the full setup.

## What you need

| Item | What it is for |
|------|----------------|
| **Steam** | Installs and launches Wuthering Waves |
| **Wuthering Waves** | The game itself, installed through Steam |
| **ProtonPlus** | Downloads the DW-Proton runner |

## Step 1: Install ProtonPlus

Install ProtonPlus from Flathub: <https://flathub.org/en/apps/com.vysp3r.ProtonPlus>, or search for **ProtonPlus** in your software or app manager.

## Step 2: Download DW-Proton

Open ProtonPlus and download the latest **DW-Proton**. Make sure you are installing it for **Steam**, shown by the icon in the top right.

![ProtonPlus downloading DW-Proton for Steam to play Wuthering Waves on Linux](/images/wuwa/wuwa1.webp)

## Step 3: Set Wuthering Waves to use DW-Proton

You can do this in ProtonPlus or in Steam. Either works.

### Option A: In ProtonPlus
Set Wuthering Waves to use DW-Proton in the compatibility settings in ProtonPlus.

![ProtonPlus compatibility setting for Wuthering Waves set to DW-Proton](/images/wuwa/wuwa5.webp)

### Option B: In Steam
Open the game's properties in Steam, go to **Compatibility** and select DW-Proton.

![Steam game properties for Wuthering Waves](/images/wuwa/wuwa2.webp)
![Steam compatibility tool dropdown with DW-Proton selected](/images/wuwa/wuwa3.webp)

Then you can play.

## Login tip

For logging in, it is best to link your Steam account to whichever login service you used before.

## Frequently asked questions

**Can you play Wuthering Waves on Linux?**
Yes. Install it through Steam and set DW-Proton as the compatibility tool, as shown above.

**Which Proton should I use for Wuthering Waves?**
This guide uses the latest DW-Proton, installed with ProtonPlus.

**Do I need to use ProtonPlus?**
ProtonPlus is the easiest way to download DW-Proton for Steam. You can then select it either in ProtonPlus or directly in Steam's compatibility settings.

**Where do I select DW-Proton in Steam?**
Open the game's properties, go to Compatibility, and choose DW-Proton from the compatibility tool list.
