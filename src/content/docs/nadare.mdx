**Nadare** is a launcher that installs and configures supported games on Linux in a single click, so you do not have to follow a manual guide step by step. It is currently in **beta**.

Pick the game, press install, play. For anything it does not cover yet, the written guides on this site still apply, and every supported game keeps its manual guide as a fallback.

## Get started

1. Download the `.AppImage` file from the [latest release page](https://github.com/frostlinuxdev/nadare/releases/latest).
2. Make it executable (`chmod +x Nadare-*-x86_64.AppImage`) or tick "Allow executing as program" in your file manager.
3. Double-click it. Nadare downloads what it needs (Proton, WebView2 and so on) on first use.

A `SHA256SUMS` file sits next to the download if you want to verify it.

## Supported games

- **Chaos Zero Nightmare**: install, update, QR login and launch. Tested on NVIDIA and AMD.
- **Arknights** (EN): install, update and launch through Proton.
- **Stella Sora** (EN): install, update and launch through Proton. It is also on Steam, which we recommend over Nadare; see the [guide](/guides/stella-sora/).

Newer betas add many more games, each marked Verified or Experimental in Nadare's Add Game list; the [release notes](https://github.com/frostlinuxdev/nadare/releases/latest) say what each version supports. Fate/Grand Order is not in the downloadable AppImage yet.

## Beta notes

- Only some games are supported, and the list grows over time.
- Things may break or change between releases.
- If something fails, use the manual guide for that game and report it on [GitHub issues](https://github.com/frostlinuxdev/nadare/issues).
- Source and full docs: [github.com/frostlinuxdev/nadare](https://github.com/frostlinuxdev/nadare).
