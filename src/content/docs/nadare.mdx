**Nadare** is an open-source launcher that installs and runs anime games on Linux. Open the **Store**, pick a game, press **Install**, then press **Play**. Nadare downloads the game from the publisher, sets up Wine/Proton for you and keeps it updated, with one profile per game. It is in **beta**.

## Get started

1. Download `Nadare-<version>-x86_64.AppImage` from the [latest release](https://github.com/frostlinuxdev/nadare/releases/latest) and, if you like, check it against the `SHA256SUMS` file next to it.
2. Make it executable (`chmod +x Nadare-*-x86_64.AppImage`) or tick "Allow executing as program" in your file manager.
3. Double-click it, open the **Store**, pick a game and press **Install**. Nadare downloads what it needs (a Proton runner and so on) on first use.

You need a Linux x86_64 desktop (Wayland or X11) with glibc 2.35 or newer (Ubuntu 22.04+, Debian 12+, Fedora 36+, current Arch) and a working Vulkan driver, including its 32-bit Vulkan support. Run `./Nadare-*.AppImage doctor` if something is missing; it prints the fix.

## Supported games

Every game has a tier. **Verified** means a maintainer installed it through Nadare and played it past the title screen. **Experimental** means the install is covered by tests but has not been played end to end, or needs a workaround.

| Game | Tier |
|---|---|
| Chaos Zero Nightmare | Verified (install, update, QR login, launch) |
| Arknights, Stella Sora | Verified |
| Brown Dust 2, Aether Gazer, Punishing: Gray Raven | Verified |
| Girls' Frontline 2 (Darkwinter build), Honkai Impact 3rd | Verified |
| Arknights: Endfield, Neverness to Everness (direct install) | Verified |
| Genshin Impact, Honkai: Star Rail, Zenless Zone Zero | Experimental (checked as far as the login screen) |
| Wuthering Waves, Mongil: Star Dive, NIKKE | Experimental |
| Girls' Frontline 2 (Haoplay global build), Neverness to Everness (publisher's launcher) | Experimental |
| Fate/Grand Order (NA) | Experimental, source checkouts only |

The written guides on this site still apply to every game, and each keeps its manual guide as a fallback.

## Beta notes

- Nadare is unofficial community software and is not affiliated with any game publisher. It may break a game's Terms of Service, so use an account you can afford to lose.
- Things may break or change between releases. Nadare shows a banner when a new release is out.
- If something fails, use the manual guide for that game and report it on [GitHub issues](https://github.com/frostlinuxdev/nadare/issues).
- Source and full docs: [github.com/frostlinuxdev/nadare](https://github.com/frostlinuxdev/nadare).
